# Butterfly layout
Ergonomic leverless controller layout by Alpenmeister

    "A layout so good, even major Chinese manufacturers are copying it now."
    ~ someone from the Open Stick Community (GP2040-CE) Discord

This highly ergonomic and modular layout is the final step in an evolution that started in 2016 with the release of Street Fighter V. It began as a split leverless layout and gained its final open-source / open-design form with the release of Street Fighter 6 in 2023.

## Evolution

It takes the familiar keyboard movement layout with a spacebar, adds the classic 6-button arcade action controls and places all the modern gamepad buttons around them in the most ergonomic way. As an added bonus, the L1/L2 buttons regain their logical position to the left of the 4 main gamepad buttons, while R1/R2 remain to the right.

## Other considerations

This layout uses the smaller arcade button size and is spaced with no rims in mind. All the buttons are as close together as possible and comfortable. For use with classical arcade buttons with a rim, the spacing needs to be widened. Only the thumb and middle buttons use the larger standard arcade button cap size, to make it easier for both hands to use them. Although this is a split layout, you can do all the shortcuts and tricks you would normally do on the original all-button controller layout with only one thumb button.
